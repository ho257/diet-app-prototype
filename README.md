# 개인용 식단 관리 앱 프로토타입

이 폴더는 iPhone 앱으로 만들기 전에 화면 흐름과 입력 방식을 확인하기 위한 브라우저용 프로토타입입니다.

## 열어보기

`index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

## 포함된 기능

- 오늘 남은 칼로리, 섭취 칼로리, 운동 칼로리, 현재 체중 확인
- 아침/점심/저녁/간식 식단 입력
- 자주 먹는 음식 빠른 추가
- 체중 기록 및 최근 추세 그래프
- Apple Watch 연동을 가정한 운동량 표시
- 운동 수동 추가
- 입력 데이터는 브라우저 안에 저장

## iOS 앱으로 옮길 때

- 화면은 SwiftUI의 `TabView` 구조로 옮깁니다.
- 저장소는 개인용 v1 기준으로 휴대폰 로컬 저장소를 사용합니다.
- Apple Watch 운동, 활동 칼로리, 체중 데이터는 HealthKit 권한을 받아 읽습니다.
- HealthKit 권한을 거부해도 수동 입력은 계속 사용할 수 있게 둡니다.
